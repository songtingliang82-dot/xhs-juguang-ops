# 小红书聚光广告投放操盘

将"小红书付费投流（聚光平台）"做成可复用的投放决策框架。核心原则：**先算账、再投放；先测试、再放量；以数据决策，不靠感觉。**

## 触发场景

- 用户要开户/开通聚光、确认行业能不能投、要什么资质
- 用户要搭建投放计划（营销诉求/广告类型/定向/出价/预算）
- 用户说"计划跑不动/没消耗/成本太高/ROI 低"，需要诊断与优化
- 用户要做留资获客（私信/表单）、内容种草、矩阵放大
- 用户要创作投放笔记、检查违禁词与合规、配置私信话术
- 用户要复盘数据、计算单粉成本/回本率、规划预算

## 工作总流程

1. **问清四要素**（信息不足时先问，勿猜）：① 行业/品类 ② 成交路径（私域加微 / 表单线索 / 电商卖货 / 到店）③ 现状（全新 / 有号有笔记 / 投过效果差 / 想放大）④ 预算量级。
2. **合规体检**：查行业准入（`references/01`）与该行业资质、违禁词红线（`references/06`）。禁入行业不硬推，直接告知并提供替代路径。
3. **定目标与策略**：按成交路径映射营销诉求（客资收集/产品种草/电商推广/种草直达），选择广告类型组合（搜索/信息流/视频流/全站）。
4. **给方案**：计划结构 + 出价倒推 + 预算分配 + 素材要求 + 承接配置（`references/02`、`04`、`05`）。
5. **落地交付**：输出可直接执行的文件（投放计划表/关键词表/笔记选题/话术），使用 `templates/`。
6. **诊断与复盘**：按 `references/03` 决策树定位问题；给出数据看板口径与优化动作（`references/05`）。

## 分场景执行要点

### 开户与资质
读 `references/01`。让用户准备：干净小红书号（无违规）+ 营业执照（经营范围覆盖）+ 行业资质。提醒：推广账号名定好再开（改名收费）、资质与专业号主体一致。

### 计划搭建（核心）
按 `references/02`。关键决策顺序：营销诉求 → 广告类型 → 笔记 → 定向 → 出价 → 预算 → 创意 → 转化组件。新计划一律"多条笔记赛马 + 指定预算 + 均匀消耗"。

### 投放诊断
按 `references/03` 的决策树逐层排查（先看有无负向操作 → 再看出价/素材/定向 → 分"新计划/老计划×跑量少/成本高"四象限），给动作而非空话（每步都带具体幅度）。

### 内容与留资笔记
按 `references/04` 给框架与公式；产出的文案需过 `references/06` 自查（医疗功效词、极限词、导流词是三大雷区）。

### 私信承接
按 `references/05`：私信通/自动回复/30秒回复率/话术结构。承接质量决定留资率，与投放同等重要。

### 数据复盘
按 `references/05` 指标口径给出结论（单粉成本、开口成本、回本率），并据 `templates/投放台账ROI.md` 结构让用户记账。

## 输出规范

- 给建议必须附"为什么"（依据指标或算账逻辑），不要只给结论。
- 所有数值默认给区间并注明适用条件；行业出价以后台"系统建议出价/大盘参考"为准，本技能数值仅作启动参考。
- 涉及他人经营数据/内部资料时提醒保密；鼓励用户验证平台最新规则（产品与界面迭代快）。
