# 私信承接与数据口径

## 一、为什么承接决定留资成败

广告把"意向用户"带到私信只完成一半。留资率（私信→加微/留资）由客服承接速度与话术决定。**私信 30 秒内回复率 ≥90% 是留资行业的关键基准**——回复慢一分钟，意向就流失一半以上。

## 二、承接配置清单

1. **私信通/私信组件**：全位置开启；配欢迎语、关键词自动回复、常见问题快捷回复；
2. **人值班**：投放时段必须有真人实时回复（自动回复只是兜底）；
3. 主账号统一查看子账号私信线索（线索管理入口），避免漏接；
4. 有条件可接第三方客服工具做消息聚合（需主账号授权）。

## 三、话术框架

- **欢迎语三段式**：问候 → 一句话资质/价值（建立信任）→ 抛开放式问题（引导用户说出需求）；
- **筛选话术**：先判断意向（预算/时间/决策角色），不急着成交；
- **价值前置**：先发"免费评估/资料/案例"这类低门槛动作，再谈加微信；
- **加微动作合规化**：用私信通名片/留资卡引导，或先给价值再"把完整版发你方便留个联系方式"——避免直接甩微信号被平台识别；
- **未开口用户跟进**：3 日内递进 2-3 次（价值→案例→最后一次才要联系方式），别第一天就轰炸。

## 四、客服效率纪律

- 回复用"你"不用"你们"，一对一感；
- 常见问题（价格/流程/时间/案例）准备 5-10 条快捷回复统一话术；
- 每个咨询会话结束做标记（意向/放弃/已成交），反哺投放人群包（平台支持基于私信行为建模）。

## 五、数据口径与复盘

### 指标定义
| 指标 | 定义 | 用途 |
|---|---|---|
| 私信开口成本 | 花费 / 发起对话人数 | 客资行业核心成本指标 |
| 留资/加微成本 | 花费 / 有效线索数 | 生意账基准 |
| 点击成本 | 花费 / 点击 | 素材质量参考 |
| 点击率 CTR | 点击 / 展现 | <3% 提示素材弱；>6% 不转化提示承接/内容问题 |
| 回本率 | 业绩 / 总成本 | 判断要不要继续投 |
| 单粉/单客成本 | 总成本 / 有效获客数 | 与可接受成本比对 |

### 生意账模板（务必记账）
- 单日口径：消耗、有效线索、单线索成本、成交业绩、回本率
- 归因口径：付费归因通常看点击后一段时间内（如 T+3/T+7），别只盯当日报表
- 注意区分：人工成本也要计入总成本算真回本率

### 判断周期
- 单日波动：观察 3 天再下结论；
- 计划去留：给足学习期（5-7 天）再定生死；
- 素材衰减：出现点击/转化连续下滑即准备替换。

## 六、复盘动作

1. 每周固定复盘：消耗×线索×成交，算单客成本与回本率趋势；
2. 归因问题到层：量少看计划/出价 → 成本高看素材/定向 → 转化差看承接/笔记；
3. 好的计划做差异化复制；稳定后按 30-50% 阶梯加预算。
