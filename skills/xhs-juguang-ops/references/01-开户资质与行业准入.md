# 开户资质与行业准入

## 开户基本流程

1. 准备：小红书账号（**无严重违规记录**）+ 营业执照（个体工商户/企业均可）。
2. 官网 ad.xiaohongshu.com → 用已认证**企业专业号（蓝V）**扫码登录 → 进入"去认证/添加行业资质"。
3. 按实际业务选行业与二级类目，提交对应资质材料 → 审核通过 → **充值**（自助约 2000 起，官方/代理对接通常 5000 起）→ 建计划投放。
4. 余额可申请退回（约 2-3 个工作日）。

## 开户细节清单

- 资质材料在有效期内；主体信息须与专业号认证一致，否则驳回。
- **推广账号名称确定后再开户**：改名可能产生费用（部分渠道约数百元）。
- 建议走官方或授权代理商开户：出问题（资质驳回/风控/退款）可直接对接。
- 一个营业执照可开多个专业号（同一执照一般可认证 2 个企业专业号并各带店铺）；个人实名与法人信息须一致，否则驳回且难换绑。

## 行业准入判断逻辑（速查）

**判断顺序**：看一级行业是否整体禁投 → 看二级类目准入/禁入 → 看资质材料是否满足。

| 类型 | 一般准入（需营业执照含相关经营范围） | 一般禁入（除非另有说明） |
|---|---|---|
| 教育 | 学历/语言/职业/线上教育、出国留学（非游学）、成人兴趣培训、教学工具 | 财商教育（涉股）、游学研学、军队文职考培等 |
| 医疗健康 | 仅少数资讯工具类 | 医美/口腔/眼科/体检/器械/OTC/保健食品等几乎全线 |
| 法律 | — | 律所/司法鉴定/公证等 |
| 商务服务 | 管理咨询、咨询策划、招聘、广告制作、会展等 | 财务税务、知识产权、出国服务（留学除外） |
| 本地生活 | 房屋维修等少量 | 家政、安保、部分家政细分 |
| 金融 | — | 几乎全线（需特批） |

- 境外主体有独立准入规则（多数类目禁入）。
- 动态规则以聚光后台"资质中心/准入查询"为准；不确定时引导用户查后台或问官方代理。
- **医疗外科有少量准入项**（如部分眼鼻类手术项目），需逐条核对，勿一刀切说"医美都禁"。

## 禁投红线（任何行业）

枪支/管制、VPN 翻墙、代写代考、假证、身份信息买卖、未版号游戏、外来物种制品、国家标识滥用（军功章/特供）、高致病菌株买卖等——见合规红线文档。
