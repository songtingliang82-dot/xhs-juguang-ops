# 投放 ROI 台账模板（生意账）

> 关键：把"人工+付费+其他成本"全部计入，才能算出真回本率。单日一行，按周汇总。

## 单日台账

| 日期 | 付费消耗 | 人工成本 | 其他成本 | 总成本 | 有效线索(加微/留资) | 单线索成本 | 成交业绩 | 累计业绩 | 回本率(业绩/总成本) | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|
| 示例 | 1000 | 150 | 25 | 1175 | 50 | 23.5 | 500 | 500 | 42.6% | 前3天正常爬坡 |
|  |  |  |  |  |  |  |  |  |  |  |

## 周汇总（示例公式说明）
- 单线索成本 = 总成本 ÷ 有效线索
- 回本率 = 累计业绩 ÷ 累计总成本
- 盈亏线：回本率 ≥ 100% 且看毛利（业绩非毛利时注意折算）

## 月度目标设定
- 当月有效线索目标：＿＿＿ 条（= 目标业绩 ÷ 成交率 ÷ 客单价）
- 允许最高单线索成本：＿＿＿ 元（由毛利与成交率倒推，见 references/02）
- 目标回本率：＿＿＿

## 复盘要点（每周）
1. 单线索成本趋势：上升？→ 看素材衰退/竞争加剧；下降？→ 考虑放量；
2. 人工成本占比：线索多了客服跟得上吗（30 秒回复率）；
3. 归因周期提醒：线索转化成交往往滞后 3-30 天，别用单日数据判断计划生死。
