# 投放诊断决策树

诊断顺序铁律：**先查"负向操作"，再看出价，再看素材，最后看大盘与生命周期。**

## 第一层：有没有近期"负向操作"？

检查最近 1-3 天是否做过：减预算 / 降出价 / 缩定向 / 缩时段 / 关创意 / 换素材。有 → 逐项反向恢复并观察 2-3 天，不要继续乱动。

## 第二层：按四象限定位（新/老计划 × 跑量少/成本高）

### A. 新计划·跑量少（不起量）
按序排查：
1. 出价低于大盘 → 提高 10%-20%（冷启动期可略高于建议价）；
2. 点击率 <3% → 封面+标题不行，换素材（别在烂素材上加价）；
3. 定向太窄 → 放宽为智能定向/扩地域；
4. 计划或账户预算不足 / 余额不足 → 补；
5. 创意未过审 → 改到过审；
6. 都排除了仍不起 → 重建计划 / 换笔记重搭，别死守。

### B. 老计划·跑量少（单天掉量 / 连续掉量）
1. 有负向操作 → 见第一层反向恢复；
2. 无负向操作但单日掉量 → 看前一日成本是否飙高导致竞争力下降 → 出价提到昨日成本水平，跑稳后再慢慢降；
3. **连续 5-7 天掉量 + 点击率/转化率持续走低 = 素材/计划衰退** → 暂停计划，用同一条好笔记新建计划；素材库要持续补新。

### C. 新计划·能跑但成本高 / 空耗不转化
1. 点击率 >6% 却不转化 → 笔记内容/末尾引导问题，优化正文与落地承接；
2. 出价高于大盘 → 压到与大盘持平；
3. 定向太泛（通投）→ 改智能或高级定向，覆盖 2000w+ 适中人群；
4. 以上无效 → 重建计划换笔记。

### D. 老计划·单日/持续成本升高
1. 大盘波动（大促/节点抢量）→ 单日波动观察 3 天，勿慌；
2. 预算激增 → 按 30%-50% 阶梯恢复；
3. 频繁改价（>2次/天）→ 停手，等模型稳定；
4. 定向扩大带来的成本波动 → 观察 2-3 天；
5. 持续升高 + 素材衰退 → 停计划用同笔记重建。

## 第三层：素材与笔记层面的判断

- 笔记取舍：基础浏览数百以上的笔记才值得投；图文在客资类常比视频好转化；
- 新笔记需做好互动区引导（评论置顶/追评）；
- 一条笔记调整出价后 5-7 天仍跑不动、点击率长期 <5% → 弃；
- 点击率 >5% 且咨询/开口不错 → 加预算放量；
- 消耗快但没人咨询 → 降价慢跑，别直接关。

## 附录：空耗 vs 假耗（成本问题的根因区分）

- **真空耗**：有曝光有点击，但无访问/无交互 → 流量质量或素材与人群错配 → 查定向与素材；
- **假空耗**：有访问有交互，但无转化 → 落地环节问题（笔记引导、私信话术、表单）→ 查承接；
- 有转化但成本高 → 单日转化 ≥10 个后再缓慢降出价（样本不足勿动）；ROI 低于保本 → 先排素材与落地页，再动出价。

## 时间节奏建议

- 前 3 天：每天看成本与量级趋势，只做幅度小的调整（提价一次/换素材一次）；
- 第 5-7 天：做第一次"去留判断"（是否衰退/是否复制放量）；
- 稳定跑 7 天以上的计划才谈复制：差异化复制（换素材换文案）而非 1:1 克隆同素材。
