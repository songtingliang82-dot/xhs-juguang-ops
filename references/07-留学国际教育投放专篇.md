# 留学 / 国际教育投放专篇

> 适用：留学申请中介、国际课程(IB/AP/A-Level)、背景提升/科研、艺术留学、低龄留学、国际学校等。以下为方法论框架，行业出价与准入以聚光后台与官方代理为准。

## 一、类目与合规（先确认能不能投）

| 业务 | 聚光类目 | 要点 |
|---|---|---|
| 留学申请/规划/中介 | 教育培训-出国留学 | 准入；营业执照含教育/留学咨询类经营范围 |
| 雅思/托福/GRE 培训 | 教育培训-语言培训 | 与留学分开选类目 |
| 国际课程(IB/AP/A-Level)辅导 | 教育培训-职业教育/线上教育 视课程形式 | 按售卖形式选 |
| 游学/研学营 | — | **一般禁入**，勿按留学投 |
| 背景提升/付费科研 | 视内容选 教育/商务服务 | 边界模糊类目先问官方代理 |

**合规红线（留学高发违规点）**：
- ❌ 承诺类：保录取/保 offer/保排名/"100% 下签"——绝对禁；
- ❌ 虚假/不可验证案例：offer 图需真实且脱敏，勿用网图；
- ❌ 冒充院校官方或"官方合作"夸大（需有真实授权凭证）；
- ❌ 极限词（最好/第一/全美Top10 保证…）；
- ✅ 可打：真实案例（隐去隐私）、规划师资质/从业年限、服务流程透明、费用透明、可验证的榜单与排名（注明数据来源）。
- 注意区分"留学咨询"与"留学中介"宣传边界，不承诺签证结果。

## 二、市场细分与人群

### 按维度拆市场（决定账号与计划怎么分）
- 阶段：低龄(初高中)/本科/硕士/博士；
- 国家：美/英/澳/加/港新/日韩/欧洲；
- 类型：普通申请 / 艺术留学 / 博士全奖 / 双非逆袭 / 考研后转留学 / 在职深造；
- 关键人群标签：**家长（31-45 女性为主，付费方）** vs **学生本人（使用方）**；信息流素材按付费方（家长）做决策话术。

### 需求旺季节奏（放量规划）
- 主申请季：每年 9-12 月（次秋入学申请高峰），预算前移 6-9 月开始蓄水；
- 规划咨询季：3-6 月；
- 节点红利：考研出分后(约2-3月)、高考后(6-7月)、夏校/背景提升暑期(4-6月)——节点前 1-2 周加投并换对应素材。

## 三、关键词体系（搜索计划核心）

分层组词（示意，需按后台拓词）：
- 核心词：留学申请、留学中介、{国家}留学、出国留学费用；
- 条件/人群词：双非能申请{国家}吗、低龄留学、艺术留学作品集、大龄留学、无语言成绩留学；
- 时间/阶段词：2027 留学申请时间线、考研后留学来得及吗、大二准备留学晚不晚；
- 专业词：{专业}留学、商科/计算机/教育 留学；
- 服务词：文书润色、背景提升、科研项目、夏校申请、签证办理。
- 埋词位置：标题 ≥ 开头 ≥ 正文；一篇笔记主打 1 个细分（垂直出爆款），不要一篇全塞。

## 四、计划结构建议（成熟打法）

| 计划 | 定位 | 预算占比参考 | 定向 |
|---|---|---|---|
| 搜索-核心+长尾 | 收高意向 | 50-60% | 无法筛人群，靠词 |
| 信息流-家长画像 | 触达付费方 | 25-30% | 31-45、女性为主、教育/亲子/消费兴趣；地域=目标客群省份城市 |
| 人群包-对标粉丝 | 抢同行客户 | 10-20% | 5-10 个对标留学号/留学考试号博主粉丝 |

- 新计划多条笔记赛马；同一条优质笔记可同时挂搜索+信息流两个计划分别测试。

## 五、素材与笔记方向（留资笔记四段公式：痛点→专业→价值→引导）

| 类型 | 钩子示例(改写勿照抄) | 目的 |
|---|---|---|
| 案例型 | 脱敏 offer/录取 + 背景条件复盘 | 结果信任 |
| 规划型 | 时间线/各阶段 checklist | 实用价值+收藏 |
| 避坑型 | 黑中介套路、野鸡大学名单、文书误区 | 权威感 |
| 对比型 | 国家/院校/方案对比 | 决策辅助 |
| 费用型 | 各国留学费用透明拆解 | 筛选预算匹配客群 |
| 人设型 | 顾问从业故事+观点 | 建立 IP，家长更信"人" |

- 家长向素材侧重：确定性（资质、合同、退费条款）、结果（案例）、风险（别耽误孩子）；
- 学生向素材侧重：可能性（我能去哪）、路径（怎么准备）、成本。
- 所有案例素材保留可验证材料备查，但对外展示脱敏。

## 六、出价与预算参考逻辑

- 用倒推法：先定"签约客户可接受成本"，再沿漏斗倒推开口/留资可接受成本。
- 留学漏斗参考（示意，因机构而异）：私信开口 → 加微 → 顾问初筛 → 面谈/测评 → 签约。签约率通常显著低于开口数，算账时务必走到"签约成本"这一层，不要被便宜的开口量迷惑。
- 预算纪律同通用篇：日预算 ≈ 该阶段目标单转化成本 × 8-10；加预算 30-50% 阶梯。
- 行业实时出价：以后台"系统建议出价/大盘参考"为准；冷启动可高 10-20%。

## 七、私信承接（留学话术要点）

- 家长高频首问：费用多少 / 成功率怎么样 / 我孩子{背景}能去哪 / 你们和别家区别；
- 开场先收"背景四件套"：在读阶段+目标国家+意向方向+预算范围 → 再给针对性建议（体现专业）；
- 低门槛钩子：免费评估/规划时间线/院校匹配表/讲座名额；
- 加微用私信通名片/留资卡；加微后 24h 内顾问回访，建立信任再谈方案；
- 30 秒回复率 ≥90%；咨询高峰期安排值班轮换。

## 八、复盘口径

- 阶段漏斗表：消耗 → 私信开口 → 加微 → 初筛 → 面谈 → 签约（各层成本都记）；
- 关键健康指标：开口成本、加微成本、**签约成本**、签约 ROI（业绩含客单毛利）；
- 素材归因：哪类素材(案例/避坑/费用)带来的线索签约率高——加预算给"高签约率素材"，而非只给"高点击素材"。
