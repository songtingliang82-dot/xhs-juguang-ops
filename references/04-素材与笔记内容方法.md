# 素材与笔记内容方法

## 一、留资/获客型笔记框架（四段公式）

**痛点场景 → 专业背书 → 给价值 → 引导留资**

1. 开头：戳具体痛点/焦虑（场景化，别空喊"你还在踩坑吗"）；
2. 中部：用经历、数据、资质建立信任（案例可展示但需可验证、勿虚假）；
3. 价值：给可执行的干货（时间线/清单/对比），让用户觉得"这号有东西"；
4. 收尾：弱引导——"需要完整版/帮你评估/发你清单"，把动作引到评论区或私信，**正文别硬留联系方式**。

> 钩子强度排序（用于封面/标题/首图）：具体数字 > 明确利益 > 悬念问题 > 对比反差。评赞比健康区间参考 1:3~1:5（赞:评）。

## 二、标题公式（通用组合）

- 数字型：`X 个...`/`从 A 到 B，我只做了 X 件事`
- 提问型：直接抛用户正在纠结的问题（痛点问句）
- 利益型：看完获得什么
- 人群+结果型：`{人群}+{方法/结果}`（例：双非/宝妈/上班族 定位前缀效果好）
- 对比/反常识型：制造认知冲突

发布前自查：无极限词（最/第一/顶级…）、无医疗功效词、无导流词硬广。

## 三、关键词埋词（搜索流量 = 免费+付费都要吃）

1. 用聚光"关键词规划工具/行业推词"或平台搜索联想找词；
2. 分层组词：**核心词**（品类大词，贵但精准）+ **长尾词**（场景+条件+人群组合，如"XX 行业 转行 来得及吗"）+ **竞品词**（谨慎）;
3. 埋词位置：标题 ≥ 正文开头 ≥ 正文中，每篇 2-3 个关键词自然融入，勿堆砌（堆词无益）；
4. 匹配方式：精准转化为主用短语匹配，想拓量再加广泛。

## 四、素材测试与筛选（赛马机制）

1. 新计划一次上 **2-5 条**不同笔记/素材，预算按 5:3:2 分层（主力/测试/替补）；
2. 以"成本达标且量稳定"为标准选优，不是只看互动高；
3. 跑赢的素材做**差异化复制**（改钩子/改角度/改人群切入），别 1:1 搬运同素材铺量；
4. 素材迭代节奏：持续小批量上新，断更素材是计划衰退主因之一。

## 五、素材复制参考框架（模仿爆款的结构化拆解）

拆解一条可借鉴素材时看四个维度：
- 发布信息：文案结构、话题标签、发布时间；
- 脚本信息：前 3 秒钩子、中间利益点、结尾行动指令；
- 成片信息：画面/人物/场景/字幕/BGM（视频类）；
- 数据信号：互动率、评论里的高频问题（=用户的真实顾虑，直接做成下一条素材选题）。

## 六、账号内容配比（投放期参考）

- 干货笔记持续养号（每周 ≥1 篇，保证账号活跃与信任）；
- 留资笔记按"发完干货后隔天再上投流笔记"的节奏，别天天硬广；
- 投放笔记选**已有几百基础浏览**或转化数据好的笔记，比全新笔记直接投更稳。
